# SRP desktop prototype

Single-file desktop search results page (SRP) for Housing.com, built on the Bricks Design System v1.2.0.

- Figma-matched SRP listing card (single, multi-BHK and new-launch project variants)
- Grid / list view toggle with equal card heights
- Airbnb-style map: price pins that declutter into dots, map card on click, search-as-you-move, expand map
- Native MapLibre GL with an OpenFreeMap vector style recoloured to Bricks tokens

Open `index.html` in a browser (or serve the folder, e.g. `npx serve`). `srp-desktop.html` is the same file.
